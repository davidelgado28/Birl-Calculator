# Calculadora Monstra em BIRL

Uma calculadora simples de linha de comando desenvolvida em **BIRL** (*Bambam's "It's show time" Recursive Language*) para treinar lógica de programação.

## Funcionalidades

O programa realiza as quatro operações matemáticas básicas com suporte a números decimais (`TRAPEZIO`):

* **1 - Soma** (`+`)
* **2 - Subtração** (`-`)
* **3 - Multiplicação** (`*`)
* **4 - Divisão** (`/`) — 

## Como executar

Você pode rodar este projeto diretamente no navegador sem instalar nada:

1. Copie o código do arquivo `calculadora.birl`.
2. Acesse o [Compilador Oficial da BIRL](https://github.io).
3. Cole o código na área de edição.
4. No campo **Entrada (stdin)**, informe a opção desejada e os dois números separados por espaço ou quebra de linha.
   * *Exemplo (somar 15 + 27):*
     ```text
     1
     15
     27
     ```
5. Clique no botão **BIRL!** e veja o resultado na saída.
